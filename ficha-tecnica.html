Setup de Meng-Âmok y formato mixto

Cerebro MIDI / Secuenciación

  • MPC LIVE 2 (sampler/looper)
  • Controlador MIDI maestro NOVATION REMOTE ZERO SL
  • Caja MIDI Thru (4 salidas)
  • Computador Toshiba Satellite S75t

Sintetizadores

  • Access Virus B Desktop / Rack
  • Dave Smith Instruments MOPHO
  • Novation NOVA Desktop
  • Waldorf BLOFELD Desktop
  • Mutable Instruments SHRUTHI-1 Desktop
  • Kurzweil K2000vp

Procesamiento

  • Compresor Alesis 3630
  • Mesa EMP8 Soundcraft
  • Interfaz TASCAM US2×2

Pedales de efectos

  • Line6 DL4, Boss DD7, Boss RC20XL
  • Zoom MG50S, Mooer Shimverb Pro, Mooer Echo Pro
  • Metalwork Distorsión

Accesorios

  • Atril para teclado
  • Atriles para micrófono (x2) y partituras (x2)
  • Micrófonos Behringer C2 (par estéreo)

Formatos de presentación

Marimba Acústica

  • Duración: 45-60 minutos
  • Espacio mínimo: 3m x 2m
  • Acústica: Preferentemente con buena reverberación natural

Meng-Âmok

  • Duración: 60-90 minutos
  • Tomas eléctricas: 2 independientes
  • Superficie: Mesa estable de 2m x 1m

Formato Mixto

  • Duración: 60-75 minutos
  • Espacio mínimo: 4m x 3m
  • Amplificación: 2 micrófonos para marimba

Requerimientos generales

Montaje45-60 minutos según formato
Desmontaje50 minutos
Temperatura18°-24°C recomendado
IluminaciónAjustable según programa

Condiciones técnicas

  • Electricidad con conexión a tierra estable
  • Sistema PA profesional con técnico de sonido
  • Mesa de mezclas mínimo 8 canales
  • Asistente para montaje/desmontaje de marimba (recomendado)
